# 一、安装步骤

解压文件管理员运行 install.cmd，输入当前程序路径。
1. nvm v：显示版本号。
1. nvm install *8.9.3*：下载安装 nodejs8.9.3 版本。
1. nvm install lastest：安装最新版 nodejs。
1. nvm node_mirror https://npm.taobao.org/mirrors/node/：使用淘宝 node 镜像，默认下载路径：https://nodejs.org/dist/v8.9.3/win-x64//node.exe。
1. nvm npm_mirror https://npm.taobao.org/mirrors/npm/：使用淘宝 npm 镜像。
1. nvm ls：列出所有安装的 node。
1. nvm ls available：查看可用的（可下载的）全部 node 版本。
