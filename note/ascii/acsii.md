# 三、控制字符解说

NUL (0, 00)  
NUL 表示空字符，常用作 C 字符串结束符；嵌入的 NUL 字节可能会让按 C 风格字符串处理文本的代码出现意外。

SOH (1, 01)  
SOH 在早期通信系统中标记报文标题开始，如今主要见于旧协议。

STX (2, 02)  
STX 在分帧传输中把正文与标题分开；现代协议通常改用明确的长度字段。

ETX (3, 03)  
ETX 标记文本块结束，检查旧式串行协议时仍有参考价值。

BEL (7, 07)  
BEL 要求终端提醒用户。现代终端可能发声或闪烁，日志中仍可能出现该控制字节。

BS (8, 08)  
BS 将光标后移；它不一定删除字节，这是终端处理中常见的区别。

HT (9, 09)  
HT 跳到下一个制表位，显示宽度取决于编辑器、终端或浏览器。

LF (10, 0A)  
LF 表示移动到下一行。类 Unix 系统使用 LF 作为行结束符，在源代码中通常写作 `\n`。

VT (11, 0B)  
VT 垂直移动，虽然如今少见，但仍属于标准 C 空白字符集合。

FF (12, 0C)  
FF 最初让纸张进到下一页；打印机和某些文本格式仍可能解释它。

CR (13, 0D)  
CR 表示回到一行开头。Windows 的行结束符将 CR 与 LF 配对，在源代码中写作 `\r\n`。

SO (14, 0E)  
SO 在终端上选择备用字符集，具体含义取决于通信设备。

SI (15, 0F)  
SI 将终端恢复到正常字符集，是 SO 的历史对应项。

ESC (27, 1B)  
ESC 开始终端转义序列。应谨慎处理不可信 ESC 字节，因为终端可能将其解释为命令。

DEL (127, 7F)  
DEL 原本用于擦除穿孔纸带位置。它是控制字符，并不等同于退格字节。
