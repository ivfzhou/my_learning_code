# 一、笔记

1. BRE 中须要转义以支持特殊正则功能的字符：`+ ? | ( ) { }`。
1. 字符类（方括号 [ ]）内部需要转义的字符：`] ^ - [ \`。

# 二、语法

## 2.1 元字符

- .：匹配任意单个字符。
- *：匹配前一个字符 0 次或多次。
- +：匹配前一个字符 1 次或多次。
- ?：匹配前一个字符 0 次或 1 次。
- {*m*, *n*}：匹配前一个字符至少 *m* 次，至多 *n* 次。
- {*m*}：精确匹配 *m* 次。
- {*m*,}：至少匹配 *m* 次。
- ^：匹配行首。
- $：匹配行尾。
- [ ]：字符类。内部的元字符没有正则功能。
- |：或运算符。

## 2.2 分组和捕获

- ( )：分组，捕获。作为一个整体，可用于量词或后向引用。
- \\*n*：后向引用。在同一个正则中可以用 \\1、\\2 引用前面捕获的分组。

## 2.3 字符类

冒号可换成 . 或 =，例如 [[=alnum=]]。
- [[:alnum:]]：字母和数字。等价于 [a-zA-Z0-9]。
- [[:alpha:]]：字母。等价于 [a-zA-Z]。
- [[:blank:]]：空格和制表符。等价于 [ \t]。
- [[:cntrl:]]：控制字符。等价于 [\x00-\x1F\x7F]。
- [[:digit:]]：数字。等价于 [0-9]。
- [[:graph:]]：可见字符（不含空格）。等价于 [!-~]。
- [[:lower:]]：小写字母。等价于 [a-z]。
- [[:print:]]：可打印字符（含空格）。等价于 [ -~]。
- [[:punct:]]：标点符号。等价于 [!-/:-@[-`{-~]。
- [[:space:]]：空白字符（空格、制表符、换行等）。等价于 [ \t\n\r\f\v]。
- [[:upper:]]：大写字母。等价于 [A-Z]。
- [[:xdigit:]]：十六进制数字。等价于 [0-9A-Fa-f]。

## 2.4 其他

- [^abc]：否定字符类，匹配除 a、b、c 之外的任意一个字符。^ 必须紧跟在 [ 之后才表示取反，否则是普通字符。
- [a-b]：表示范围。
- ?=*n*：匹配任何其后紧接指定字符串 *n* 的字符串。
- ?!*n*：匹配任何其后没有紧接指定字符串 *n* 的字符串。
- \d：数字。等价于 [0-9]。
- \D：非数字。等价于 \[^0-9]。
- \w：单词字符（字母、数字、下划线）。等价于 [a-zA-Z0-_]。
- \W：非单词字符。等价于 \[^a-zA-Z0-9_]。
- \s：空白字符（空格、制表符、换行等）。等价于 [ \t\n\r\f\v]。
- \S：非空白字符。等价于 \[^ \t\n\r\f\v]。
- \b：单词边界。
- \B：非单词边界。

## 2.5 标志

- i：执行对大小写不敏感的匹配。
- g：执行全局匹配（查找所有匹配而非在找到第一个匹配后停止）。
- m：执行多行匹配。
- u：启用 Unicode 模式。
