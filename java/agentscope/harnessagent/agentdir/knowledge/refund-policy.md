# 退换货与退款政策

## 1. 七天无理由退货

- 适用范围：除**定制类、鲜活易腐、拆封后易影响人身健康的商品、虚拟商品**外的全部实物商品。
- 时长：自签收次日 0 点起 **7 天（168 小时）**内申请，商品需保持**完好**（配件、赠品、包装齐全）。
- 运费：非质量问题由**买家承担**；已购运费险的按运费险条款赔付（见 4）。
- 特殊品类：
  - 大家电：需提供**开箱视频**或物流红章证明，否则破损争议不予支持。
  - 美妆个护：塑封拆封后不支持无理由退货，但质量问题不受此限。

## 2. 质量问题退换货

- 时效：签收后 **15 天**内可申请退货退款，**30 天**内可申请换货或维修。
- 凭证：需提供**商品问题照片/视频**；电子类还需提供**检测报告**（超过 15 天时）。
- 运费：由**商家承担**，往返运费一并计入退款。
- 同一订单同一商品**累计 3 次**质量问题，按《消费者权益保护法》支持全额退款不退货（需人工复核）。

## 3. 退款金额构成

```
退款金额 = 商品实付金额 + 商家承担运费（如适用） - 已使用的平台补贴分摊
```

- 优惠券、满减按**商品实付比例**分摊，退款时仅退分摊后的实付部分，券不返还。
- 积分抵扣按 100 积分 = 1 元折算后退还积分，不退现金。
- 已开票订单需先**红冲发票**再退款，退款时效顺延 1-3 个工作日。

## 4. 运费险

- 保额：按寄件距离分档，最低 **8 元**，最高 **25 元**，以保单为准。
- 触发：仅当退货原因为**质量问题或商家责任**时自动理赔；无理由退货不赔付。
- 理赔时效：退货签收后 **72 小时**内到账买家账户。

## 5. 退款到账时效

| 支付渠道 | 到账时效 |
| --- | --- |
| 余额 / 平台账户 | 即时 |
| 支付宝 / 微信 | 1-3 个工作日 |
| 银行卡 | 3-7 个工作日 |
| 信用卡 | 7-15 个工作日 |
