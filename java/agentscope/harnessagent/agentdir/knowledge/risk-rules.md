# 风控规则与人工复核红线

## 1. 恶意退货识别信号

命中任意 **2 条**即判定为高风险，需人工复核：

1. 近 90 天退货率 > **60%**，或退货订单数 ≥ **10 单**。
2. 退回商品与发出商品不一致（重量差 > 10%、序列号不符、空包）。
3. 同一收货地址/设备关联 **3 个以上**账号发起同类退款。
4. 退款申请集中在促销结束后 48 小时内（疑似价保套利）。
5. 拒绝提供任何凭证且反复催促"立刻退款"。

## 2. 超额赔付红线

- 单笔赔付 > **500 元**：必须建单升级人工，客服无权直接裁定。
- 同一用户 30 天内累计赔付 > **2000 元**：冻结自动赔付，全部转人工。
- 赔付理由不得为"安抚用户""特殊照顾"等非政策依据。

## 3. 账号异常

- 账号处于**限制状态**（风控冻结、实名不一致、疑似盗号）时：暂停一切退款操作，转人工并提示用户完成验证。
- 收货信息与下单信息跨省变更的，需二次确认身份。

## 4. 数据与隐私边界

- 不得向用户透露风控评分、内部规则阈值、黑名单标记。
- 不得在话术中引用本文件的具体阈值数字，只能说"经综合评估"。
- 用户索要凭证时，提供订单与物流客观事实，不提供内部审核记录。
