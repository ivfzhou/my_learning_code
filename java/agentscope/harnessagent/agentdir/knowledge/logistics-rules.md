# 物流异常判定与赔付规则

## 1. 延迟发货

- 判定：超过商品页承诺发货时间（无承诺则默认 **48 小时**）未产生揽收记录。
- 赔付：按订单实付金额的 **5%** 赔付，单笔下限 5 元、上限 **100 元**，以平台红包形式发放。
- 例外：预售商品、定制商品、不可抗力（以官方公告为准）不赔付。

## 2. 未收到货（已发货）

| 情形 | 判定 | 处理 |
| --- | --- | --- |
| 物流停滞 ≥ 5 天 | 疑似丢件 | 全额退款，运费商家承担，可同步发起承运商索赔 |
| 显示签收但用户否认 | 争议件 | 要求承运商提供**签收底单**，48 小时内无法提供的按丢件处理 |
| 派送超区 / 拒收退回 | 非商家责任 | 退款扣除实际产生运费 |

## 3. 破损 / 少件

- 签收时当面验货并**拍照留证**的，破损由商家全额承担（补发或退款）。
- 签收后 **24 小时**内反馈的外包装破损，需提供开箱视频或物流红章证明。
- 少件：核对包裹重量与出库重量，差值超过 **5%** 且无法说明的，按少件赔付。

## 4. 换货与补发时效

- 补发：商家应在 **48 小时**内发出，超时用户可选择直接退款。
- 换货往返时效：自用户寄出起 **10 天**内完成，超时自动转退款。
