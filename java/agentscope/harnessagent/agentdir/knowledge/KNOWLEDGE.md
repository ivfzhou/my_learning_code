# 售后知识库索引

本目录是售后场景的**唯一政策口径来源**。系统提示只会加载本索引，正文用 `read_file` 按需打开。

| 文档 | 内容 | 什么时候查 |
| --- | --- | --- |
| `refund-policy.md` | 七天无理由、质量问题、退款时效与金额构成 | 判断"能不能退、退多少、多久到账" |
| `logistics-rules.md` | 签收/未签收、延迟发货、丢件破损的判定与赔付 | 判断"物流异常谁担责、赔多少" |
| `risk-rules.md` | 恶意退货识别、超额赔付红线、人工复核触发条件 | 判断"要不要拦截/升级人工" |

## 通用口径（高频，直接记住）

- 时效一律从**签收次日 0 点**起算；未签收的从**预计送达日次日**起算。
- 所有金额单位为**元**，保留两位小数；优惠按商品实付比例分摊，不退优惠券面值本身。
- 平台先行赔付上限：单笔 **500 元** 由客服直接裁定，超过必须建单升级人工。
- 与用户沟通时须给出**具体日期**，不允许出现"大概""近期"等模糊表述。
