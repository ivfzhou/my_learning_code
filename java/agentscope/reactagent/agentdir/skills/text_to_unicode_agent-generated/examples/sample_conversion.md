# 示例：文本转 Unicode 码点

## 示例 1：英文文本

**输入文本：** `Hello`

**输出格式：** U+XXXX

| 位置 | 字符 | 码点 |
|------|------|------|
| 1 | H | U+0048 |
| 2 | e | U+0065 |
| 3 | l | U+006C |
| 4 | l | U+006C |
| 5 | o | U+006F |

**完整码点序列：**
```
U+0048 U+0065 U+006C U+006C U+006F
```

---

## 示例 2：中文文本

**输入文本：** `你好世界`

**输出格式：** U+XXXX

| 位置 | 字符 | 码点 |
|------|------|------|
| 1 | 你 | U+4F60 |
| 2 | 好 | U+597D |
| 3 | 世 | U+4E16 |
| 4 | 界 | U+754C |

**完整码点序列：**
```
U+4F60 U+597D U+4E16 U+754C
```

---

## 示例 3：混合文本（含 Emoji）

**输入文本：** `A☺🎉`

**输出格式：** U+XXXX

| 位置 | 字符 | 码点 | 说明 |
|------|------|------|------|
| 1 | A | U+0041 | 基本拉丁字母 |
| 2 | ☺ | U+263A | 白色笑脸（BMP 范围内） |
| 3 | 🎉 | U+1F389 | 派对拉炮（BMP 范围外，5位） |

**完整码点序列：**
```
U+0041 U+263A U+1F389
```

---

## 示例 4：不同输出格式对比

**输入文本：** `Hi`

| 格式 | 结果 |
|------|------|
| U+XXXX（默认） | `U+0048 U+0069` |
| \uXXXX | `\u0048 \u0069` |
| 0xXXXX | `0x0048 0x0069` |
| 十六进制 | `0048 0069` |
| 十进制 | `72 105` |
| HTML实体 | `&#72; &#105;` |
