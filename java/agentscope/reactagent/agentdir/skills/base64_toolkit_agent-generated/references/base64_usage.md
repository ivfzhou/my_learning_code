# Base64 使用参考指南

## 1. 什么是 Base64？
Base64 是一种基于 64 个可打印字符来表示二进制数据的编码方式。它常用于在文本协议（如电子邮件、JSON、XML）中传输二进制数据，或者将二进制数据嵌入到文本格式中（如 HTML 的 Data URL）。

## 2. 字符集
Base64 使用以下 64 个字符：
- `A-Z` (26 个大写字母)
- `a-z` (26 个小写字母)
- `0-9` (10 个数字)
- `+` 和 `/` (2 个特殊符号)
- `=` (用于末尾填充，使总长度为 4 的倍数)

## 3. 常见应用场景
1. **数据传输**：在 HTTP 请求或 JSON 中传递图片、文件等二进制内容。
2. **Data URL**：在 HTML/CSS 中直接嵌入小图片，减少 HTTP 请求。
   示例：`<img src="data:image/png;base64,iVBORw0KGgo...">`
3. **Basic 认证**：HTTP Basic Authentication 将 `username:password` 进行 Base64 编码后放入 Header。
4. **混淆代码**：在前端开发中，有时会将关键配置或代码片段进行 Base64 编码（注意：这不是加密，极易被破解）。

## 4. 注意事项
- **不是加密**：Base64 仅仅是编码，任何人都可以轻松解码。请勿用于存储密码或敏感信息。
- **体积增加**：Base64 编码后的数据体积会比原始数据大约 33%。
- **URL 安全性**：标准的 Base64 包含 `+` 和 `/`，在 URL 中可能引起问题。如果在 URL 中使用，建议采用 **URL-safe Base64**（将 `+` 替换为 `-`，`/` 替换为 `_`，并移除末尾的 `=`）。
- **填充符**：如果原始数据长度不是 3 的倍数，Base64 编码末尾会添加 1 个或 2 个 `=` 作为填充。解码时通常需要保留这些填充符。
