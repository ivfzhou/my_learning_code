# JSON 语法参考指南

## 1. 基本数据类型
- **字符串**: 必须使用双引号 `"` 包围。
- **数字**: 整数或浮点数，不支持 NaN 或 Infinity。
- **布尔值**: `true` 或 `false`（全小写）。
- **空值**: `null`。
- **对象**: 键值对集合，键必须是字符串。
- **数组**: 有序列表。

## 2. 常见语法错误
1. **使用单引号**: `{'key': 'value'}` ❌ -> `{"key": "value"}` ✅
2. **键名未加引号**: `{key: "value"}` ❌ -> `{"key": "value"}` ✅
3. **尾随逗号**: `{"a": 1, "b": 2,}` ❌ -> `{"a": 1, "b": 2}` ✅
4. **包含注释**: JSON 标准不支持注释 `//` 或 `/* */`。
5. **未闭合的括号**: 确保 `{}` 和 `[]` 正确匹配。
6. **控制字符**: 字符串中不能直接包含换行符或制表符，需使用 `\n` 或 `\t` 转义。

## 3. 最佳实践
- 保持键名使用驼峰命名法 (camelCase) 或下划线命名法 (snake_case)。
- 避免在 JSON 中存储函数或 undefined 值。
- 对于大型 JSON 文件，使用格式化后的版本进行版本控制，以提高可读性和 diff 对比效率。
- 在传输时，可使用压缩（minify）后的版本以减小网络带宽占用。
